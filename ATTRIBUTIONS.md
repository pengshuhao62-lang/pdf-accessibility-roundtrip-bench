# Test corpus attributions

## PDF/UA-1 Reference Suite 1.1

The `corpus/ua1/reference/` files come from the PDF Association's PDF/UA-1 Reference Suite 1.1:

<https://pdfa.org/resource/pdfua-reference-suite/>

The suite is made available under the Creative Commons Attribution 4.0 International license. The contributing organizations and individuals named by the source are retained in the source distribution. The files are included for testing and demonstration; they are not modified by the benchmark.

## Self-authored fixtures

The files under `corpus/ua1/` and `corpus/ua2/` outside the `reference/` directory are generated by `tools/generate_fixtures.py`. They contain fictional text only and are dedicated to the public domain under CC0-1.0 for benchmark reuse.

# v3 diagnostic-capacity overlay

The optional builder downloads veraPDF Library's `BaseValidator.java` at tag
v1.30.2, verifies its SHA-256, and changes one diagnostic-storage constant. It
retains the veraPDF Consortium's original copyright and dual GPLv3+/MPLv2+
notices and uses the MPLv2+ option. Original and patched sources are preserved
beside the local build; no modified upstream JAR is redistributed.
See [build details and upstream sources](docs/verapdf-full-checks.md).
