# Manual review checklist

Automated results in this project cover machine-verifiable PDF/UA checks and limited structural signals. They are not a complete screen-reader accessibility assessment.

For a selected representative case, a reviewer may record:

- Case ID, tool version, veraPDF version, and macOS version.
- Whether the output opens in macOS Preview.
- Whether headings or document navigation remain usable.
- Whether the observed reading order is reasonable.
- Whether image alternative text remains available in a structure-aware viewer.
- Whether tables remain understandable.
- Whether form fields remain present and usable.
- Any difference between the automated result and the observed behavior.

Manual observations are stored separately from the automated pass rate. Do not include private PDFs or screenshots containing personal data in a public report.
